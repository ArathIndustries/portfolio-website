## How this page is made

This page lives at `content/showcase/studio-showcase.mdx`. Between the components you are reading ordinary Markdown: headings, **bold**, `code`, lists and links. The studio shows each Markdown run as one block whose text is edited in the side pane; everything else below is a JSX component with typed props.
