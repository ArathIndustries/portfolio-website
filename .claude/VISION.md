# Portfolio Website — Vision

## One-line pitch
Professional portfolio site for Arath Industries — workshop/lab aesthetic with neon sign hero, showcasing engineering + tech projects.

## Problem
Need a professional web presence to land contracts and showcase work. Must balance personality (neon workshop aesthetic) with professionalism.

## Target user
Engineering firms, municipalities, startups, small businesses needing tech help. Also potential employers.

## Value proposition
"I don't just build the tool — I study the workflow, talk to the team, and build something that actually fits." IE background + technical skills + interpersonal/change management instincts.

## Site structure (planned)
- `/` — Landing (hero neon sign, value prop, featured case studies, CTA)
- `/work` — Case studies (OpenChambers, Datathon, Digital Twins, AI Assistant, etc.)
- `/work/[slug]` — Individual case study
- `/about` — Story, skills, education
- `/blog` — Technical writing
- `/contact` — Hire me / CTA
